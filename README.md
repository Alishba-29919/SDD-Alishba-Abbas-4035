# SDD-Alishba-Abbas-4035
VocalDine: AI-Powered Voice-Interactive Smart Menu System
VocalDine is my final year project designed to modernize the dining experience. It replaces traditional paper menus with an AI-driven, voice-interactive web application, allowing customers to browse and order food hands-free.

🛠 Tech Stack
=> I have built this project using the following technologies:

=> Frontend: React.js for building dynamic UI components.

=> Styling: Tailwind CSS for a modern, responsive design.

=> AI/Voice Integration: Web Speech API.

=> Analytics :	Chart.js.

# Key Features
Voice-First Navigation: Users can search and select menu items using voice commands.

Smart UI/UX: High-fidelity, responsive design that works seamlessly on mobile devices.

Real-time Interaction: Instant feedback system that visualizes voice commands for the user.

Category Filtering: Easily filter between breakfast, lunch, and dinner categories.


# Developer's Note
This project was developed as a final-year student project to bridge the gap between AI and hospitality services. I focused on making the user interface clean and intuitive to ensure that even non-tech-savvy users can use the voice-ordering feature without difficulty.
